Core Concept

Beyond Plain Words: Rich Speech Transcription

Standard ASR produces words but strips away non-verbal speaker signals and environmental soundscapes. Surround Sound captures the missing acoustic context and weaves it directly into the transcript with exact word-level alignment.

Standard ASR (Whisper)
"Hey there, can you tell me where I am going? So I want to understand the road was blocked okay."
× Non-verbal speaker vocalizations (coughs, breaths) and surrounding environment (horns, traffic) are completely lost.
✨ Surround Sound (Rich Transcript)
"Hey [cough 0.68-2.00] there, can you tell me where I am going? [breath] So I want to understand <horn> the road was blocked </horn> okay."
✓ [tag]: Speaker sounds inserted inline at start timestamp.
✓ <tag>...</tag>: Ambient background sounds wrapping the exact words they overlap.

Model Architecture

Network Architecture (Figure 1 from Paper)

Architecture with tensor shapes measured with forward hooks on the released model. A 64-band log-mel spectrogram is downsampled by five convolutional blocks into 201 time steps (40 ms stride), contextualized by six Transformer encoder layers, and mapped to 54 independent class probabilities.

End-to-End Network Pipeline & Tensor Shapes

Figure 1 (Main)

Audio → Spectrogram: 8s waveform (128,000 samples at 16 kHz) converted via STFT 512 (10 ms hop) into a 64-band log-mel spectrogram (1 × 64 × 801).
5 Conv Blocks: Proportional 3D volumes shrink frequency (64 → 32 → 16 → 8 → 4) and time (801 → 801 → 801 → 401 → 201), producing 192 × 4 = 768 features per 40 ms step.
Transformer & Output: Linear projection to 256 dimensions with sinusoidal position encodings → six Transformer encoder layers (8 heads, d_ff=1024, GELU) → linear sigmoid layer outputting 201 × 54 class probabilities.

Tap to enlarge
1. Front-End Spectrogram
64 Log-Mel Bins • 801 Steps
STFT 512, 25 ms window, 10 ms hop, 50–8000 Hz, compressed as 10log10(x+1e-9) and scaled to [-1, 3].
2. Five Conv Blocks
866K Params (15% of model)
Channels: 48 → 48 → 96 → 96 → 192. Strides shrink frequency 64→4 and time 801→201. Each step draws on ~0.33s receptive field.
3. Transformer Encoder
6 Pre-Norm Layers (82%)
d_model=256, 8-head self-attention, d_ff=1024, GELU, dropout 0.1. Full 8s global acoustic context per frame.
4. Classification Head
54 Sigmoid Binary Heads (<1%)
Linear projection from 256 → 54 classes. Produces an independent frame-level probability track on a 40 ms grid.

(a) Training Pipeline, (b) Streaming Inference with ASR & (c) Inside the Blocks

Figure 1 (Modules)

(a) Training: Multi-task loss combining frame-level BCE and clip-level BCE (0.25×) over real speech windows, synthetic mixtures, and acoustic augmentations (noise, reverb, telephony bandpass).
(b) Inference: Streaming audio of any length split into 8s windows (2s hop), passed through per-class hysteresis and median thresholding, and integrated with timestamped Whisper ASR tokens for rich transcription.
(c) Inside the Blocks: Detailed schematics of the 5 Conv blocks (2 × [conv 3×3, BatchNorm, ReLU] with residual shortcuts and frequency/time strides) and the 6 pre-norm Transformer encoder layers (LayerNorm, 8-head self-attention, LayerNorm, GELU feed-forward 256→1024→256).

Training Dynamics & Validation AP

Recovering Timestamps via CTC Forced Alignment

Many valuable speech datasets (like NonverbalTTS) mark non-verbal sounds inside written transcripts (e.g., "I wanted to [laughter] tell you...") without giving timestamps. We used a Wav2Vec2 CTC forced aligner to locate the boundary of surrounding words, recovering exact timestamps for 6,360 out of 8,620 sounds.

Quickstart

Get Started in 3 Lines of Code

Surround Sound works out of the box with PyTorch and any Whisper backend (OpenAI Whisper or Hugging Face Transformers).

from sed import Detector, load_audio, rich_transcript, clean # Load model weights & threshold profile directly from Hugging Face Hub det = Detector.from_pretrained("theboringai-work/surround-sound", profile="sensitive") # 1. Detect timestamped events in any audio file (ffmpeg supported) events = det.detect("call.mp3") print("Detected Events:", events) # [{'label': 'cough', 'start': 0.68, 'end': 2.0, 'prob': 0.92}, ...] # 2. Extract raw 40 ms probability tracks times, probs = det.frame_probs(load_audio("call.mp3")) # 3. Seamlessly merge with word timestamps from any Whisper ASR # words = [(word, start_sec, end_sec), ...] text = rich_transcript(words, clean(words, events)) print("Rich Transcript:", text) # 'Hey [cough] there, can you tell me where I am going? <horn> the road was blocked </horn> okay.'
# Transcript with inline speaker tags + environmental noise + timestamps sed-infer call.mp3 # Run events only on an entire directory without ASR (JSON Lines output) sed-infer recordings/ --asr none --json events.jsonl # Customize operating profile, filter unwanted tags, or override thresholds sed-infer call.wav --profile balanced --hide breath,lip_smack --times
# Install prerequisites brew install ffmpeg # macOS (or: sudo apt install ffmpeg on Ubuntu) # Install surround-sound and inference dependencies pip install git+https://github.com/theboringai-work/surround-sound.git # Optional: install whisper for transcript generation pip install openai-whisper
